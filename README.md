# 📱 Telco Customer Analysis

An end-to-end **Data Analytics project** focused on analyzing telecom customer data to understand customer behavior, service usage, churn patterns, contract types, payment methods, and overall customer retention.

The project uses data analysis and visualization techniques to transform telecom customer data into meaningful business insights and support data-driven customer retention strategies.

---

## 📌 Project Overview

The objective of this project is to analyze telecom customer data and understand the factors associated with customer churn and retention.

The analysis focuses on:

* Customer demographics
* Customer tenure
* Contract types
* Internet and phone services
* Payment methods
* Monthly charges
* Total charges
* Customer churn
* Churn patterns
* Customer retention

The project follows an end-to-end analytics workflow:

**Raw Data → Data Cleaning → Data Transformation → EDA → Customer Analysis → Churn Analysis → Visualization → Business Insights**

---

## 🎯 Business Objectives

The main objectives of this project are:

* Analyze overall customer behavior

* Analyze churn across different contract types
* Analyze customer tenure
* Understand the impact of monthly and total charges
* Analyze internet and phone service usage
